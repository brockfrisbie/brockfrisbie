# BrockFrisbie Django Project

This project will eventually replace my HTML-based website.  

Starting with a Django project with an app called bitcoin, which displays the current price of Bitcoin, fetched from the CoinGecko API, with automatic updates every 10 seconds.

## Features
- Live Bitcoin price in USD.
- Auto-refreshing display via AJAX.

- Python 3.11 or higher
